MUHAMMAD UZAIR - PORTFOLIO WEBSITE
==================================
Static website (HTML/CSS/JS). No build step needed.

Files:
  index.html            - main page
  assets/style.css      - design
  assets/main.js        - menu, animations, image zoom
  assets/img/           - project photos and Revit model views
  assets/docs/          - CV and portfolio PDF (download buttons)

Deploy on GitHub Pages:
  1. Create a new repository on github.com (e.g. uzair-portfolio), set to Public.
  2. Click "uploading an existing file" and drag ALL contents of this folder
     (index.html + assets folder), then click "Commit changes".
  3. Go to Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
  4. After 1-2 minutes the site is live at https://<username>.github.io/<repo-name>/

To edit text: open index.html in any editor (VS Code / Notepad) and change the words.
